1 · สกุลเงิน

ใช้ Emerald เป็นสกุลเงินหลัก — ไม่ลงมอดเงินตราเพิ่ม (ลดความซับซ้อน และ Bountiful/villagersplus รองรับ emerald ตรงๆ อยู่แล้ว) เพิ่ม Festival Token (ไอเท็มพิเศษ) เป็นสกุลเงินชั้นสอง สำหรับอีเวนต์/ของพรีเมียมเท่านั้น ในเฟสหลัง

3 · NPC ซื้อขาย FAUCET DRAIN

4 · กระดานบาวน์ตี้ (Bountiful) QUEST

เครื่องยนต์หลักของเศรษฐกิจ — ให้ "ทิศทาง" ว่าควรหาอะไร รางวัลดีกว่าขายเปล่า เควสหมุนเปลี่ยนเรื่อยๆ ยืนยันจาก jar แล้วว่า Bountiful 6.0.4 รองรับ objective แบบ item/item_tag/criteria และ reward แบบ item และ command (มีคลาส BountyTypeCommand)

4.1 ส่งของ (objectives)

Decree (หมวด)ตัวอย่างงานจำนวน
Fisherman 🎣ส่ง #fff:uncommon_fish / rare_fish / ปลาชนิดที่ระบุ4–16
Farmer 🌾ส่ง #fff:crops / พืชชนิดที่ระบุ16–64
Chef 🍳 (ใหม่)ส่ง #fff:dishes / เมนูที่ระบุ4–12

4.2 รางวัล (rewards) — ผสม 3 แบบ

ประเภทตัวอย่างบทบาท
💠 Emerald FAUCET{type:item, content:"minecraft:emerald"} จำนวนตาม worthรายได้หลัก
⭐ แต้มสกิล QUEST{type:"command", content:"puffish_skills experience add @p fff_angler 100"}เร่งปลดสาย Puffish — เชื่อมเศรษฐกิจเข้ากับสกิลตรี
🎁 ของหายากหนังสือมนตร์, Heart of the Sea, ของเทศกาลล่อใจ/ของสะสม
จุดเชื่อมสำคัญ: reward แบบ command ทำให้ "ส่งของ = ได้แต้มสกิล" ได้โดยตรง เศรษฐกิจกับสกิลตรีเลยไม่แยกกัน — ยิ่งทำเควส ยิ่งเก่งขึ้น

5 · Festival Token & อีเวนต์ FESTIVAL (เฟส 3)

ชั้นอัตลักษณ์ของแพ็กชื่อ "Festival" — จัดอีเวนต์เป็นรอบ:

  • Biggest Catch — ส่งปลาหายากสุด · Cook-Off — ส่งเมนูพรีเมียม · Harvest Fair — ส่งพืชครบชนิด
  • ส่งของในอีเวนต์ → ได้ Festival Token → แลกของตกแต่งพิเศษ, ของ cosmetic, gear หายาก, หรือแต้มสกิลก้อนใหญ่

Festival Token ทำได้ 2 ทาง (เลือกตอนลงมือ): (ก) จองไอเท็ม vanilla ตัวหนึ่งเป็น token เลย — ง่าย เสถียร; (ข) ไอเท็มคัสตอมผ่าน data-mod — สวยกว่า แต่ต้องมีไฟล์ jar เพิ่ม

6 · Sink ส่วนตัว (มีอยู่แล้ว แค่จูน)

spiceoffabric + diet ให้บัฟเมื่อกิน "หลากหลาย/ครบหมู่" อยู่แล้ว จูนให้คุ้มจริง → กองปลา 500 ตัวไร้ค่า แต่กิน 50 เมนูต่างกันได้แม็กซ์เลือด/บัฟ = ผลักคนให้ทำอาหารหลากหลาย (กินวัตถุดิบทิ้ง) แทนกักตุน เชื่อมเข้าสาย Chef พอดี

7 · สมดุล & กันเงินเฟ้อ DRAIN

ความเสี่ยงอันดับ 1 = เงินเฟ้อ. ถ้ารับซื้อใจดีเกิน emerald ท่วม ราคาหมดความหมาย เกมจืด
มาตรการรายละเอียด
บันไดมูลค่าดิบถูกเสมอ · แปรรูป/หายากแพง → รางวัลอยู่ที่ "ความพยายาม" ไม่ใช่ "ปริมาณ"
จำกัดก๊อกmax_uses ต่อ NPC + demand ให้ราคาตกเมื่อขายซ้ำ + จำกัดจำนวนบาวน์ตี้ที่รับได้พร้อมกัน (ตั้งใน config Bountiful)
ท่อระบายจริงDecorator (ของตกแต่งไม่รู้จบ) · ค่า respec สกิล · ค่าเข้าอีเวนต์ · gear/มนตร์แพงๆ

8 · แผนลงมือ (เป็นเฟส)

1
Tag backbone + NPC ซื้อขาย — สร้าง #fff:common_fish/crops/dishes + เทรด buy/sell (ก๊อก+ท่อระบายพื้นฐาน) · ได้ผลไวสุด เห็นวงจรเงินทันที
2
Bountiful decrees — พูล fish/crop/dish → emerald + แต้มสกิล + ของหายาก (เครื่องยนต์หลัก)
3
Festival Token + อีเวนต์ — ชั้นเทศกาล + cosmetic sink
4
จูน spiceoffabric/diet + รอบปรับสมดุล — ทดสอบราคาจริง ปรับก๊อก/ท่อระบายให้นิ่ง

ข้อควรรู้ก่อนลงมือ (ตรงๆ)

  • ต้องยืนยัน schema reward command ของ Bountiful ตอน build — เจอคลาสแล้วว่ารองรับ แต่รูปแบบ JSON ที่ถูกต้องต้องทดสอบจริงก่อน (เหมือนที่เคยเจอปัญหา field ไม่รองรับ)
  • ต้อง sync ขึ้น Server ด้วย — ระบบนี้เป็น datapack/config ทั้งหมด ทำฝั่ง client ทดสอบก่อน แล้วค่อยยกขึ้น server (ยังค้างอยู่ตั้งแต่คราวก่อน)
  • เทรด NPC ที่แก้ผ่าน datapack จะมีผลกับ villager ที่ เกิด/เลื่อนขั้นใหม่ — ตัวเดิมอาจต้องรอ refresh
  • ต้อง ปิดเกมสุดแล้วเปิดใหม่ ทุกครั้งที่แตะไฟล์ jar (ถ้าเฟส 3 เลือก token แบบ data-mod)
ขอคอนเฟิร์ม: โอเคกับโครงนี้ไหม? ถ้าโอเค ผมเริ่ม เฟส 1 ก่อน (tag + NPC ซื้อขาย) — เห็นวงจรเงินไวสุด แล้วค่อยไล่เฟสถัดไป หรือถ้าอยากปรับตัวเลข/สลับลำดับเฟส บอกได้เลย
