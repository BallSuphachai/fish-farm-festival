A · ช่องโหว่ทางเศรษฐกิจ (ปั๊มของได้ไม่จำกัด)

#ปัญหาผลกระทบข้อเสนอ
A1พ่อค้าเทศกาลรับซื้อของที่ทำฟาร์มอัตโนมัติได้แลก Token: Snowball (ฟาร์ม Snow Golem), ไข่ (Chicken Nest), ดอกไม้ (Bone Meal), ขนแกะ, น้ำผึ้ง/รวงผึ้ง, ฟักทอง, เห็ด, Sweet Berries, Sea Pickle, Cookie, กล้าสนAFK ฟาร์ม Token ได้ไม่จำกัด → Nether Star 80 Token ได้ง่ายมาก ทั้งระบบเทศกาลพังเอาออกจากการรับซื้อแลก Token
A2Chef XP ได้จากการกินอะไรก็ได้ ครั้งละ 4กิน Dried Kelp รัวๆ → Chef เลเวลเร็ว → Mastery Crate ไม่จำกัด (มี Feast + Token)ให้ XP เฉพาะอาหารจากมอด ตามระดับเมนู (simple 2 / basic 4 / complex 8 / gourmet 14 / feast 20)
A3Market ขายไข่ปลา Hybrid Aquatic (6 มรกต) → วางใส่ Spawner ได้ปลาตกลงมาเป็นไอเท็มปลาที่นับในเควส/Derby → ฟาร์มปลาไม่จำกัดเอาไข่ปลาออกจาก Market (เหลือไข่ปลาของ Better Fish Tanks ที่ใช้กับตู้ปลาเท่านั้น)
A4Mastery Crate มีโอกาสได้ Festival Token 35%Token รั่วนอกเทศกาลลดเหลือ 15%

B · ความไม่สมดุล

#ปัญหาข้อเสนอ
B1Chef "Ironbelly" ให้ Resistance II (ลดดาเมจ 40%) จากสตูว์ธรรมดาได้แทบตลอดเวลา → การต่อสู้ง่ายเกินไปอีกเปลี่ยนเป็น Resistance I นานขึ้น + Absorption

B3สัตว์เลี้ยงใน Market (หมาป่า, ม้า ฯลฯ) ใช้กับ Spawner ได้เช่นกันไม่ได้ของมีค่าจากการฟาร์ม (ยอมรับได้)

C · ความเสถียรและความพร้อมของ CurseForge

#ปัญหาข้อเสนอ
C1hungersdelight ไม่ได้ติดตั้งจาก CurseForge (ดูเหมือนมาจาก GitHub/Modrinth) — CurseForge อาจไม่อนุมัติแพ็กที่แนบมอดของคนอื่นที่ไม่อยู่ใน CurseForgeต้องตัดสินใจ (ถามด้านล่าง)
C2มีไฟล์สำรอง (*.bak) ในโฟลเดอร์ config และไฟล์ทดสอบที่ root ของ instance จะติดไปกับ Exportย้ายไปเก็บที่ _backup_pre_1.3 นอก config
C3mod ของเรา 12 ตัวยังเป็นเวอร์ชัน 1.0.0 ทั้งหมด ผู้เล่นแยกไม่ออกว่าเวอร์ชันไหนตั้งเวอร์ชันเป็น 1.3.0 ทุกตัว
C4Error ใน log ที่เหลือมาจากมอดอื่น (snowyspirit, dustydecorations, brewery, farmers_structures) ไม่กระทบการเล่นไม่ต้องแก้

D · Server

#ปัญหาข้อเสนอ
D1Server ยังไม่มี mod ของเรา 11 ตัว และยังมี Terralith กับ Bakery ที่ถูกลบจาก client แล้ว → client 1.3 จะเข้า server ไม่ได้ซิงค์ mod ให้ตรงกับ client (ไม่เอา mod ฝั่ง client อย่าง Sodium/Iris)
D2โลกเดิมบน server สร้างด้วย Terralith + Bakery → ภูมิประเทศเก่าเพี้ยน บล็อก Bakery หาย และไม่มีสิ่งก่อสร้าง/ระบบใหม่ในพื้นที่ที่สำรวจแล้วต้องตัดสินใจ (ถามด้านล่าง)
D3config ของ server ไม่ตรงกับ client (ต้นไม้สกิลใหม่, Bounty, Backpack, Market ฯลฯ)คัดลอก config ทั้งหมดจาก client ไป server
