🎉 เทศกาลและพ่อค้าเทศกาล

ทุกอย่างที่ต้องรู้เกี่ยวกับ 4 เทศกาลของแพ็ก · Festival Token · ใบสั่ง · Stamp Card · ตัวเลขอ้างอิงจากแพ็ก 1.4.3

สรุปสั้น: ทุกเทศกาลมี พ่อค้าเทศกาล มาหาคุณถึงที่ ทุกอย่างทำที่แผงของพ่อค้า ไม่ต้องพิมพ์คำสั่ง เอาปลาและพืชของฤดูมาขายแลก Festival Token ทำ ใบสั่ง เก็บ แสตมป์ แล้วเอา Token ไปซื้อของในร้านของพ่อค้า

1. ปฏิทินเทศกาล

  • 1 ฤดู = 24 วันในเกม · 1 ปี = 96 วัน (วันในเกม = 20 นาทีจริง)
  • แต่ละเทศกาลเริ่มวันที่ 9 ของฤดู และอยู่ 16 วัน (วันที่ 9–24) ช่วงวันที่ 1–8 ให้เก็บของของฤดูไว้ก่อน
  • พ่อค้าจะ มาหาคุณเอง เมื่อเทศกาลเริ่ม ทุกคนมีพ่อค้าของตัวเอง ถ้าเดินไกลจนหลง ใช้ปุ่ม [Call the merchant] ในแชตเรียกกลับ พ่อค้าไม่รับดาเมจและถูกผลักไม่ได้

2. Festival Passport — สมุดพกเทศกาล

  • พ่อค้าแจก Festival Passport ให้ทุกคนตอนเจอกันครั้งแรก เอาเมาส์ชี้ดูข้อมูลได้เลย: ฤดู วันที่ จำนวนวันก่อนเทศกาล ปลา พืช และจานประจำฤดู ใบสั่งของคุณ แสตมป์ และแต้ม Derby
  • อัปเดตเองตลอดเวลาที่อยู่ในกระเป๋า ทำหาย? ขอใหม่ได้ที่พ่อค้าโดยแลกกับกระดาษ 1 แผ่น
  • มีหน้าสรุปแบบแชตให้ด้วย พิมพ์ /trigger fff_almanac (เรียกว่า Seasonal Almanac) แต่ไม่จำเป็นต้องใช้

3. ร้านของพ่อค้า — เมนูแบ่งเป็นหมวด

รายการเทรดแบ่งเป็นหมวด แต่ละหมวดมีแถวหัวข้อที่เทรดไม่ได้ (ชี้ดูคำอธิบายได้):

In Seasonปลาและพืชประจำฤดู ขายได้ 2 Token ต่อครั้ง ในอัตราที่ดีกว่าปกติ

Emerald Shopของฟุ่มเฟือยที่จ่ายด้วย Emerald Block

4. In Season — ขายของประจำฤดู ปรับใน 1.4.3

  • ทุกรายการจ่าย 2 Festival Token ต่อครั้ง ในอัตราที่ดีกว่าการขายทั่วไป (ปลาหายากอย่าง Mahi-Mahi และ Sturgeon ตัวเดียวได้ 2 Token)
  • เทรดได้ 3 ครั้งต่อรายการต่อวันในเกม (สูงสุด 6 Token ต่อรายการต่อวัน) พอขึ้นวันใหม่ รายการจะ รีสต็อกเอง ไม่ต้องทำอะไร
  • จำนวนที่ต้องใช้ต่อ 1 ครั้งดูในตารางด้านล่าง (ผัก/พืชใช้จำนวนมากขึ้นใน 1.4.3 และเพิ่มชนิดปลาที่ตกง่ายให้เลือกเยอะขึ้นแล้ว)

5. Sell for Tokens — ขายของทั่วไป

  • ได้ 1 Token ต่อครั้ง ตัวอย่างอัตรา: ผักเช่น Cabbage, Lettuce, Barley, Oat ใช้ 24 ชิ้น · Hops, Ginger, Chili Pepper 16 ชิ้น · ปลาทั่วไป เช่น Cod, Salmon, Bluegill 10 ตัว · เมนูของเทศกาลบางอย่าง 2–8 ชิ้น
  • จำกัดสูงสุด 3 Token ต่อรายการต่อวันในเกม (รายการที่ได้ 1 Token เทรดได้ 3 ครั้ง) แล้วรีสต็อกเองตอนขึ้นวันใหม่
  • ปลาในหมวดนี้มีเยอะที่สุดตอนฤดูร้อน (Derby)

เหตุผลของขีดจำกัด: Token เป็นสกุลที่ทำง่าย จึงจำกัดไม่ให้ขายของชนิดเดียวรัวๆ จนได้ Token ท่วม เก็บของหลายชนิดไว้ขายจะได้ผลดีกว่า

6. Seasonal Orders — ใบสั่ง 2 ชุดสลับปี ใหม่ใน 1.4.3

  • แต่ละเทศกาลมี 3 ใบ ใบละ พืช + ปลา ได้ Token และ Emerald ทำได้ ปีละครั้งต่อใบต่อคน ถ้าเทรดใบเดิมซ้ำในปีเดียวกัน พ่อค้าจะ คืนของให้ ไม่เสียของ
  • 2 ชุดสลับปี: ปีในเกมคู่ (ปีที่ 0, 2, 4 …) ใช้ ชุด A ปีคี่ใช้ ชุด B รางวัลต่อช่องเท่ากันทุกชุด ปีในเกม = 96 วัน ตรงกับ Stamp Card ตัว Passport, Almanac และพ่อค้าจะแสดงชุดของปีนั้นให้เอง
  • เมนูประจำฤดูแลกได้ 3 Token พร้อมแสตมป์ ด้วย
  • ใบสุดท้ายของฤดูหนาวต้องใช้ พืชนอกฤดู (มี * ในตาราง) ต้องปลูกใน เรือนกระจกที่หลังคาเป็นกระจกสี (สีไหนก็ได้ กระจกใสไม่นับแล้ว) และจุดไฟให้สว่าง ทำได้จะปลดล็อกความสำเร็จ Out of Season

7. Festival Stamp Card — บัตรแสตมป์ประจำปี

  • เก็บให้ได้ 20 แสตมป์ต่อปี แต่ละเทศกาลมี 5: มาเยี่ยมพ่อค้า, ใบสั่ง 3 ใบ และเมนูประจำฤดู
  • รางวัล: 5 แสตมป์ = 5 Token + เค้ก · 10 = 10 Token + เมล็ดหายาก · 15 = Festival Treasure สุ่ม 1 ชิ้น · 20 = ถ้วย Festival Champion Trophy
  • บัตรเริ่มใหม่ทุกปีในเกม (96 วัน) ไม่มีย้อนเก็บ แต่รางวัลที่ได้แล้วเป็นของคุณ
  • ความสำเร็จ Hall of Fame: Festival Champion และ Festival Legend (เก็บบัตรเต็มสามใบในสามปีที่ต่างกัน)
  • กิจกรรมประจำเทศกาลไม่ให้แสตมป์ และไม่มีเป้าหมายให้ไล่ตาม

8. Festival Treasure — ข้อเสนอเดียวในเทศกาล

ที่บนสุดของ Token Shop คุณจะเห็น Festival Treasure 1–2 ชิ้น (ชิ้นที่สองมีโอกาสราวครึ่งหนึ่ง) สุ่มให้แต่ละคนไม่เหมือนกัน ซื้อได้ ครั้งเดียวต่อชิ้นต่อเทศกาล และไม่รีสต็อกรายวัน ของแพงสุ่มเจอได้ยากกว่า

9. Token Shop และ Emerald Shop ปรับราคาใน 1.4.3

  • ราคาใน Token Shop เพิ่มเป็นสองเท่า ทุกรายการที่จ่ายด้วย Token ใน 1.4.3 (ยกเว้น Festival Treasure) เพราะ Token เฟ้อเร็ว ตัวอย่าง: Diamond Hoe / Knife 40, Heart of the Sea 30, Diamond Fishing Rod 50, Bee Nest (Blossom Fair) 24
  • เมล็ดและต้นกล้าแพงขึ้นตามราคาตลาด ตัวอย่าง: Asparagus Seeds 4 เมล็ด 24 Token, เมล็ดองุ่น 2 เมล็ด 20 Token, Apple Tree Sapling และ Dark Cherry Sapling 8 Token
  • Sniffer Egg ไม่มีขายด้วย Token แล้ว ซื้อได้เฉพาะด้วย Emerald Block ที่ Blossom Fair

Emerald Shop ของที่จ่ายด้วย Emerald Block แยกตามเทศกาล:

10. กิจกรรมประจำเทศกาล

  • Grand Fishing Derby — เหรียญ Derby: แต้ม Angler XP ที่ได้ระหว่าง Derby นับเป็นแต้ม Derby · Bronze 100 แต้ม = 3 Token · Silver 250 = 5 Token · Gold 500 = 8 Token · วัน Derby Day (วันที่ 8) แต้มนับสองเท่า (Angler XP ใน 1.4.3 เพิ่ม 5 เท่า แต่เหรียญปรับให้ยากเท่าเดิม)
  • Blossom Fair — Planting Day (วันที่ 4) · Harvest Feast — Feast Night (คืนวันที่ 12) · Christmas มีซานต้ากับ Jingle the Elf

เคล็ดลับ

  • สะสมปลาและพืชของฤดูไว้ตั้งแต่วันที่ 1–8 ของฤดู แล้วค่อยมาขายตอนเทศกาลเริ่ม (วันที่ 9)
  • In Season ให้ Token ดีที่สุดต่อของที่ใช้ แต่จำกัดต่อวัน ขายแค่ที่ครบ 3 ครั้ง แล้วเก็บของที่เหลือไว้วันถัดไป
  • ทำใบสั่งให้ครบทุกใบทุกเทศกาล ได้ทั้ง Token, Emerald และแสตมป์ ปีถัดไปใบสั่งจะเปลี่ยนเป็นอีกชุด
  • เก็บ Token ไว้ซื้อ Festival Treasure ที่ต้องการ ราคาสูงสุดต้อง 64 + 16
  • ปลูกพืชฤดูร้อนใน เรือนกระจกกระจกสี ไว้ล่วงหน้า สำหรับใบสั่งฤดูหนาว
